# Drop your photography here

The site currently ships with generated SVG placeholders. To use real
photographs, put the image files in this folder using the names below, then
say so and they will be wired into the catalogue with proper alt text,
hotspot cropping and blur placeholders.

Accepted formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.
Aim for ~2000px on the long edge; they are optimised at build time.

## The five reference photographs

These slots are named after the images already shared, and each one is matched
to the product in the sample catalogue that was designed from it.

| `kaftan-stairs.jpg` | Man on the stairwell in the cream kaftan with the single-line face and terracotta pocket | `sankofa-applique-kaftan` — primary |
| `group-sky.jpg` | Four models shot from below against blue sky, wax print and jacquard | Homepage hero + `harmattan` collection hero |
| `fan-peplum.jpg` | Woman in the teal peacock-fan peplum with bell sleeves and matching cap, green backdrop | `adinkra-fan-two-piece` — primary |
| `damask-pair.jpg` | Two women in the bronze and teal damask boubou and gele, on the street | `damask-ceremonial-boubou` — primary |
| `wave-couple.jpg` | Couple in the red-and-white wave-print co-ord, in the garden | `akoma-wave-co-ord` — primary |

## Anything else

Additional photographs are welcome — name them `look-01.jpg`, `look-02.jpg`
and so on and they will go into the lookbook.

## The better long-term route

Once Sanity is connected (see the main README), photographs are uploaded in
the Studio instead of committed to the repo: drag them onto a product, set the
hotspot so crops never cut a face badly, and publish. That is the workflow the
site is built around — this folder is a shortcut for getting real imagery in
before the CMS exists.
